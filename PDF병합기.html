    페이지 범위 입력

    쉼표( , )로 구분해서 입력하세요. 범위 하나가 PDF 파일 하나로 저장됩니다.
    예: 1-3, 5, 8-10 → 1~3쪽, 5쪽, 8~10쪽 세 개의 파일

    🗂️
    페이지를 뽑아낼 PDF 파일 하나를 끌어다 놓으세요
    또는 이 영역을 클릭해서 파일을 선택하세요
    📄

    저장할 페이지 선택

    선택 0쪽

    저장할 페이지를 클릭해서 고르세요. 다시 클릭하면 선택이 풀립니다.
    Shift 키를 누른 채 클릭하면 사이의 페이지를 한꺼번에 고를 수 있습니다. 저장할 때는 원래 페이지 순서대로 모입니다.
